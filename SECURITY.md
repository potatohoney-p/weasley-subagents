# Security Policy

## Supported versions

Security fixes are applied to the latest released version of Weasley Subagents.

## Reporting a vulnerability

Do not open a public issue for an undisclosed vulnerability. Use GitHub's private security-advisory flow for `potatohoney-p/weasley-subagents`. If that is unavailable, email `potatohoney.p@gmail.com` with the affected version, reproduction steps, impact, and any suggested mitigation.

You should receive an acknowledgement within 72 hours. Please allow time for validation and a coordinated release before publishing details.

## Sensitive data

Remove API keys, session contents, Gist identifiers, credentials, and personal data from reports. Session sharing is opt-in, but exported sessions may still contain sensitive context; inspect them before upload.
