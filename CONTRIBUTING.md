# Contributing to Weasley Subagents

Thank you for helping improve the project.

1. Open an issue for substantial behavior or API changes before implementing them.
2. Create a focused branch and keep unrelated changes out of the patch.
3. Add or update tests for changed behavior.
4. Run `npm ci`, `npm run test:all`, `npm run typecheck`, and `npm run pack:check`.
5. Document user-visible configuration and migration changes.

Pull requests should explain the problem, the chosen approach, validation performed, and any compatibility or security impact. Contributions are licensed under Apache-2.0 when submitted.
